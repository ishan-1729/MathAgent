# Library

The library is for small high-impact identities, lemmas, and transformations. These should be compact enough for agents to load frequently and strong enough to change a proof search.

Avoid dumping trivial algebra here except in `untriaged_tagebuch/`.

`untriaged_tagebuch/` is where Kieren can initially put many identities before filtering. Promote only the identities that have clear triggers, status, and relevance.
