# Glossary

**Vierzahlensatz**: If integers `a, b, c, d` satisfy `ab = cd`, then there are integers `p, q, r, s` such that `a = pq`, `b = rs`, `c = pr`, and `d = qs`. The name is nonstandard and should be preserved in this repo.

**Tagebuch**: Kieren's working notebook stream of identities, observations, and proof fragments. Unfiltered material should enter `knowledge/library/untriaged_tagebuch/` first.

**Finite elementary descent**: A proof strategy that constructs a smaller positive integer solution from a supposed minimal counterexample, using only elementary tools.

**Squeeze sequence**: A method that traps values between adjacent terms or bounds, often forcing equality or contradiction.

**Method**: A larger proof technique with recognizable triggers, transformations, downstream moves, and failure modes.

**Library identity**: A compact high-impact lemma, identity, or trick that can unlock several proofs.

**Proof attempt**: A recorded run or human draft for a problem, including loaded context, strategy, proof status, failure points, and evaluation hooks.

**Contamination**: Accidental inclusion of a full standard proof or benchmark solution in a context intended for independent workflow evaluation.

**Percentage compilable**: The rough fraction of a Lean attempt that checks before the first unresolved theorem, failed tactic, or placeholder blocks the proof.
