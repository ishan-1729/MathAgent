# Contamination Policy

Solved demonstrations belong in `examples/`.

Target problem folders should not include full standard proofs unless intentionally seeded and clearly marked.

Standard proofs may be referenced as known externally, but should not be copied into problem folders by default.

If a problem is example-adjacent, mark it in the problem statement or evaluation notes.

The `papers/` folder is allowed as architecture inspiration for workflow design. It should not be treated as a source of benchmark problem solutions unless a run is intentionally marked as seeded or contaminated.

If a paper includes theorem examples, prompts, or formal proof snippets, do not copy those into target problem folders by default.
