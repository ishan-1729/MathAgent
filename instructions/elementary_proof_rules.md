# Elementary Proof Rules

For MathAgent, an elementary final proof may use:

- integer arithmetic;
- divisibility;
- congruences;
- inequalities;
- finite descent;
- gcd and coprimality;
- parity;
- elementary factorization;
- explicitly listed methods in `methods/`.

"Elementary" is a project rule for final artifacts, not a claim about historical priority or the only legitimate way to prove a theorem.

When using an allowed method, record the loaded method file and any problem-specific normalization.
