# Proof Attempt Protocol

Use this structure for future proof attempts:

1. Problem statement.
2. Allowed methods loaded.
3. Candidate strategy.
4. Step-by-step proof sketch.
5. Explicit elementary checks.
6. Places where proof may fail.
7. Lean formalization plan.
8. Evaluation record link.

Every nontrivial mathematical claim should be marked as conjectural, sketch, verified, Lean-checked, or failed.
