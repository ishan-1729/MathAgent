# Allowed Inputs

Allowed:

- elementary integer arithmetic and divisibility;
- congruences / modular arithmetic;
- gcd and coprimality (Bézout, Euclid's lemma);
- polynomial reasoning over the integers (Vieta's formulas for a quadratic, the factor
  theorem);
- the extremal / well-ordering principle and finite / infinite descent;
- size / bounding (inequality) arguments;
- listed methods in `knowledge/methods/`.

No special per-problem external citable is required for this problem.

Disallowed as final proof tools (global denylist categories):

- unique factorization in rings of algebraic integers (UFDs);
- ideals / class groups / class field theory; algebraic number fields;
- elliptic curves; modular forms / modularity; algebraic geometry;
- `p`-adic theory beyond `v_p` and elementary congruences;
- Catalan / Mihailescu; Baker's theory of linear forms in logarithms;
- analytic number-theory machinery;
- computational brute force without an explicit elementary finite bound.
